Installation

How to install?

Installation

Install the released package from PyPI:

uv venv --python 3.11
source .venv/bin/activate
uv pip install poem-ravenframework

Clone

git clone git@github.com:idaholab/POEM.git
cd POEM
uv sync --python 3.11
source .venv/bin/activate

The uv sync command creates .venv, installs POEM in editable mode, and installs the runtime dependencies listed in pyproject.toml.

Run Web GUI

From a source checkout, run the Streamlit GUI with:

uv sync --python 3.11
uv run --with-requirements app/requirements.txt streamlit run app/streamlit_app.py

Open the Streamlit URL printed in the terminal, usually http://localhost:8501. See gui for the GUI workflow details.

Build Documentation

uv sync --python 3.11 --extra docs
source .venv/bin/activate
cd docs
make html

Test

cd POEM/tests
poem -i lhs_sampling.xml
